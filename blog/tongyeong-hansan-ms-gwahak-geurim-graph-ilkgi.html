과학 그래프는 '가로축과 세로축이 무엇인지 → 선이 어떻게 변하는지 → 그래서 무엇을 말하는지' 순서로 읽고, 마지막에 한 문장으로 바꿔 말해 보게 하는 것이 좋아요. 중학교 과학 교과서는 실험 결과나 원리를 그림·그래프·표로 보여 주는 경우가 많아서, 이걸 읽지 못하면 글을 다 읽어도 내용이 잡히지 않아요. 한산중학교 과학 시험과 수행평가에서 무엇을 보는지는 과학 선생님 안내와 학교 평가계획을 기준으로 확인해 주세요.

한눈에 보기
  • 1단계: 제목과 축(단위 포함) 읽기
  • 2단계: 늘어나는지, 줄어드는지, 그대로인지
  • 3단계: 한 문장으로 바꿔 말하기
  • 그림은 화살표와 이름표부터

그래프 읽는 순서

  1. 제목 읽기 — 무엇에 대한 그래프인지 확인해요.
  2. 축 읽기 — 가로축과 세로축이 무엇이고 단위가 무엇인지 소리 내어 말해요.
  3. 변화 보기 — 선이 올라가는지, 내려가는지, 평평한지 봐요.
  4. 문장으로 — "○○이 커질수록 △△은 ~한다"로 바꿔 말해요.

학습 예시: 그래프를 문장으로

아래는 그래프를 문장으로 바꾸는 방법을 보여 주려고 만든 예시예요.

  • 그래프: 가로축은 가열 시간(분), 세로축은 물의 온도(℃)
  • 변화: 처음에는 올라가다가 어느 순간부터 평평해짐
  • 문장: 물을 계속 가열하면 온도가 올라가다가, 끓기 시작하면 온도가 더 이상 오르지 않는다.

평평해지는 부분처럼 '모양이 바뀌는 곳'이 시험에서 자주 묻는 부분이에요.

그림은 화살표와 이름표부터

과정이나 구조를 보여 주는 그림은 화살표가 가리키는 방향과 각 부분의 이름표부터 확인해요. 화살표를 따라가며 "먼저 ~하고, 다음에 ~한다"고 순서대로 말해 보면 그림이 설명하는 과정이 정리돼요.
